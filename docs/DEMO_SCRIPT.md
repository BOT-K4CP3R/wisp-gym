# 90-second demo script

Record on the emulator (or a real device). Say clearly that the emulator has no real motion, so **Demo mode**
replays a synthetic accelerometer stream through the same detector as the real sensor.

| Time | Action | What to say |
|---|---|---|
| 0:00 | Home screen with the creature | "Wisp grows from real training. Nothing to log, no account, no cloud." |
| 0:10 | Toggle **Demo mode** on, tap *Load 2-week demo history* | "The emulator has no motion, so this is a clearly labelled simulation." |
| 0:20 | *My week → Play 14-day evolution* | "Each muscle group grows a body part. Rest days make it recover." |
| 0:35 | *Why is Wisp like this?* | "Everything is explainable: these are the real numbers behind its state." |
| 0:45 | *Start workout → Squat → Start set* (scenario *Slowing 10 reps*) | "Reps are counted from motion alone, whatever the phone orientation." |
| 1:00 | The stop cue appears with the explanation | "It learned my fresh tempo; now reps are 30% slower, so it says rack it." |
| 1:10 | *End set / Finish workout*, back home | "The creature updated. Three sessions in 72 h and it asks for a rest day, never punishes." |
| 1:20 | Home screen widget | "The widget shows it without opening the app. All data stays on the phone." |
