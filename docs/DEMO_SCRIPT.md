# 90-second demo script

Record on the emulator (or a real device). Say clearly that the emulator has no real motion, so **Demo mode**
replays a synthetic accelerometer stream through the same detector as the real sensor.

| Time | Action | What to say |
|---|---|---|
| 0:00 | Home: creature tile, Strength ring, Move, Recovery, activity dots | "Wisp grows from real training. No account, no cloud." |
| 0:10 | Settings (top right): **Demo mode** on, *Load 2-week history* | "The emulator has no motion, so this is a clearly labelled simulation." |
| 0:20 | Week tab: *Play 14-day evolution* | "Each muscle group grows a body part. Rest lets it recover." |
| 0:35 | Insights tab | "Every value is explainable: these are the numbers behind its state." |
| 0:45 | Orange tab-bar button: *Start set* | "Reps are counted from motion alone, in any phone orientation." |
| 1:00 | Ring turns orange, label says "rack it", Fatigue row turns orange | "Reps got slower and weaker, so it tells me to stop." |
| 1:10 | *End set*, tick button, back on Home: Wisp sleepy / resting | "Over-training makes it ask for rest. It never punishes." |
| 1:20 | Launcher: the home-screen widget | "The widget shows it without opening the app. Data stays on the phone." |

A ready-made narrated version is attached to the GitHub release (`wisp-gym-demo.mp4`) and can be regenerated with
`submission/make_video.py`.
